# Ícones JADLOG BRÁS

Coloque os seguintes ícones nesta pasta:

- `launchericon-192x192.png` - Ícone para PWA (192x192)
- `launchericon-512x512.png` - Ícone para PWA (512x512)

## Logo da Jadlog

O arquivo `logo.png` deve ser colocado na pasta `app/static/` (raiz dos arquivos estáticos).

## Screenshots

Para o PWA, coloque screenshots na pasta `screenshots/`:
- `mobile.png` - Screenshot mobile (1080x1920)
